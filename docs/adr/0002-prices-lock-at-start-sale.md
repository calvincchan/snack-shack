# Price, deal size and type lock at Start sale

Sales are worked out as units sold × price, which only holds if one price applies all day. So at Start sale each lineup item's price, deal size and type are copied onto the sale day. Edits made on the Items tab during a sale apply from the next sale day (the UI shows "today $2"). The Items tab is the one place to edit price, type, storage and name; anyone on the team can edit any item.

## Considered options

- **Separate clearance or sale price** (one-day or timed): rejected as confusing. Changing the price on the Items tab does the same job.
